Политика конфиденциальности

Обновлено: 24 октября 2026 г.

CHIPSDAF Autopilot — личная программа владельца YouTube-канала CHIPSDAF.

  • Через вход Google программа получает доступ только к каналу владельца: загрузка роликов (youtube.upload) и чтение статистики канала (youtube.readonly).
  • Ключ доступа хранится только на компьютере владельца и никуда не отправляется, кроме серверов Google.
  • Программа не собирает, не продаёт и не передаёт третьим лицам никакие данные пользователей.
  • Доступ можно отозвать в любой момент: myaccount.google.com/permissions.

Использование данных, полученных через API Google, соответствует Google API Services User Data Policy, включая требования Limited Use. Программа использует YouTube API Services; см. также YouTube Terms of Service и Google Privacy Policy.

Privacy Policy

Last updated: October 24, 2026

CHIPSDAF Autopilot is a personal tool of the owner of the CHIPSDAF YouTube channel.

  • Through Google sign-in it accesses only the owner's channel: uploading videos (youtube.upload) and reading channel statistics (youtube.readonly).
  • The access token is stored only on the owner's computer and is sent nowhere except Google servers.
  • The app does not collect, sell or share any user data with third parties.
  • Access can be revoked at any time at myaccount.google.com/permissions.

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. The app uses YouTube API Services; see also the YouTube Terms of Service and the Google Privacy Policy.
